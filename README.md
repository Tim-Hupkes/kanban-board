# Done & Dusted

A small Kanban board built with React, TypeScript, Vite and Zustand.

## Features

- Add tasks to the To Do column
- Move tasks from To Do to Doing to Done
- Remove completed tasks
- Persist board state in localStorage

## Tech Stack

- React 19
- TypeScript
- Vite
- Zustand

## Getting Started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Run linting:

```bash
npm run lint
```

Create a production build:

```bash
npm run build
```
